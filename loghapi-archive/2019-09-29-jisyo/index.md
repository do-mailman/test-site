辞書登録使ってますか？

辞書登録は、デフォルトのままでは変換できない固有名詞などを登録する機能ですが、そのほかにも時間を短縮したり、ミスを減らしたり、考えを深堀りするのにも使えます。

そこで、今回はおすすめの辞書登録語句をご紹介します。表には辞書登録語句の例をまとめました。

## １．固有名詞

たとえばiPad ProやiPhone、Apple Watchなどのガジェットです。こうした固有名詞をすべて一から打つのはめんどくさいので辞書登録しています。

他にも、よく使う会社名、間違いやすい会社名などにも使えますね。

メールや書類で会社名を間違えると、恥ずかしいですむならいいですが、先方の心証を悪くすることもありますからね。

| **入力する文字** | **変換後** |
| --- | --- |
| いｐ | iPhone |
| いぱｄ | iPad |
| あｐ | Apple Watch |
| ぶり | ブリヂストン |
| びっぐかめら | ビックカメラ |

## ２．挨拶系

次は挨拶系です。

メールなどで繰り返し使う挨拶系の語句は、辞書登録しておくことで時間を短縮することが可能です。

細かいですが、繰り返しリターンが得られます。

| **入力する文字** | **変換後** |
| --- | --- |
| いつおせ | いつもお世話になっております。 |
| あり | ありがとうございます。   ありがとうございました。 |
| おつ | お疲れ様です。 |
| ごか | ご確認よろしくお願い致します。 |
| よろ | よろしくお願いします。 |

## ３．曜日

次は曜日です。たとえば(月)を打つとき、かっこをわたしは半角で打ちたいのです。

でも、半角にするには一度半角と全角への切り替えをしなければならず、大変めんどくさいのです。

そこで「（」を変換すれば、すべての曜日が出るようにしてあります。

| **入力する文字** | **変換後** |
| --- | --- |
| （ | (月)   (火)   (水)   (木)   (金) |

## ４．話し言葉→書き言葉

話し言葉と書き言葉を変換するということもやっています。

私のいる職場では書類に話し言葉を入れてしまうと、直される風土があるので、気をつけられるように辞書登録をしています。

たとえば話し言葉を変換すると、書き言葉に変換します。

変換することで、話し言葉と書き言葉について思い出せますし、意識に刷り込むこともできます。これは、まぁ職場によるところではありますね。

| **入力する文字** | **変換後** |
| --- | --- |
| いつも | 通常 |
| おなじ | 同一 |
| だんだん | 次第に |

## ５．深堀する

他にも変換を通して、深掘りすることもできます。

たとえば「アイディア」という単語を「あいｄ」と入力すれば変換できるようにしているのですが、その他にも「アイディア for」と変換もできます。

アイディアと変換したということは、なにかしらのアイディアを思いついたということです。

ではそのアイディアは誰のためなのか？なんのために使えるのか？

そういった点まで深掘りすることを思い出すための変換です。

他にも「効果」や「目的」といった単語にも使える考え方です

| **入力する文字** | **変換後** |
| --- | --- |
| あいｄ | アイディア   アイディア for |
| もくてき | 目的   目的 for |
| こうか | 効果   効果 for |

## おまけ（理系編）

一応理系というか化学系な職場なので、やっておくと便利だなーという辞書登録も載せておきます。

あまり関係がない方はとばしてください。

まずは使用している分析機器です。たとえばSEMなら「せｍ」で変換できるようにしています。

さらに使用している機器も一緒に変換できるといいでしょう。例えば「せｍ」と入力するとSEM（TM-3000）と変換できます。

他にもよく使う単位も登録しておくと便利ですね。

| **入力する文字** | **変換後** |
| --- | --- |
| せｍ | SEM   SEM（使用機器） |
| たんい | \[mPa・s\]   \[-\] |
| ｐｈ | pH |
| どし | ℃ |

## 終わりに

辞書登録は地味ですが、継続的なリターンがあります。手軽に試せますので、気になるものは、ぜひ試してみてくださいね！
